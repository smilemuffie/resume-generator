快速上手

  1. 打开页面，左侧加载示例 JSON，右侧已渲染预览。
  2. 在编辑器里直接修改姓名、公司、项目等字段，预览即时更新。
  3. 顶栏选择模板、点色块换主题色、切中/EN。
  4. 点 导出 PDF，在打印对话框另存为 PDF。

所有数据保存在浏览器 localStorage，刷新不丢，换电脑需手动导出 JSON 备份。

模板

5 套模板任选，顶栏下拉切换，样式与主题色独立记忆。

  • 极简 Minimal — 单栏无衬线，大留白，细点分隔
  • 纯净 Pure — 以极简为蓝本，highlights 以 1. 2. 3. 数字编号呈现
  • 表格 Tabular — 工作经历以 2 列表格展示，左公司右摘要
  • 基础 Basic — 单栏衬线，传统专业风，微软雅黑
  • 现代 Modern — 左侧浅色侧边栏 + 右侧主体

主题色

顶栏色块点击即换色，标题、色条、标签、链接等强调元素同步变色。每个模板各自记忆配色，切换模板不会丢失。

使用技能

技术栈字段

在 work 与 projects 每一项下可填 stack 字段（字符串数组），渲染为公司名下、项目名下的强调色 tag。

{
  "company": "某科技公司",
  "stack": ["React", "TypeScript", "Vite"]
}

效果：React TypeScript Vite（tag 形式，加粗）。想隐藏某条的技术栈？在该项加 "isStackShow": false 即可。

预览配置弹窗

顶栏齿轮按钮打开，可全局控制：

  • 展示工作经历技术栈 — 取消勾选则所有工作经历下方技术栈 tag 隐藏
  • 展示项目经历技术栈 — 取消勾选则所有项目经历下方技术栈 tag 隐藏

状态持久化，刷新保留。

{{stack}} 占位符

在 projects 的 description 里写 {{stack}}，渲染时会替换为该项目的 stack 以「 + 」连接。

{
  "description": "基于 {{stack}} 构建的中台组件库，覆盖 30+ 场景。",
  "stack": ["React", "TypeScript", "Rollup"]
}

渲染为：基于 React + TypeScript + Rollup 构建的中台组件库，覆盖 30+ 场景。

stack 为空时 {{stack}} 会被清除。仅 projects 的 description 生效。

中英双语

顶栏 中 / EN 切换。整份简历按语言分版本，两版数据独立存储、互不影响。适合准备中英两版简历。

导出 PDF

顶栏 导出 PDF 调起浏览器打印对话框：

  • 目标另存为 PDF
  • 纸张选 A4
  • 边距选「无」（页面边距已由模板内置）
  • 勾选「背景图形」以保留强调色背景

自动分页：内容超出 A4 自动续页，区块标题仅在首页出现，不会跨页截断。

FAQ

数据存在哪？

全部在浏览器 localStorage。换电脑或清缓存会丢失，请用编辑器「导出 JSON」按钮备份。

怎么恢复示例数据？

顶栏 JSON模版下载 获取完整模版，粘贴回编辑器即可。

哪些字段支持 HTML？

basics.summary、basics.highlights[]、work.summary、work.highlights[]、projects.description、projects.highlights[] 可写 <b>、<a> 等标签；其他字段（姓名、公司名）自动转义。
